# ADR-0002: Вибір Node.js (NestJS) для розробки REST API бекенду

Статус: прийнято

## Контекст
Для швидкої розробки REST API (із дедлайном MVP до 1 грудня) та забезпечення взаємодії мобільного застосунку клієнта з веб-панеллю баристи й POS-системою кав'ярні необхідний продуктивний та чітко структурований бекенд-фреймворк.

## Рішення
Обрати фреймворк **NestJS** (на базі Node.js та TypeScript) для побудови архітектури сервера.

## Наслідки
* **Переваги:**
  * Чітка модульна структура (Modules, Controllers, Services), що зручно для команди з 2-4 осіб.
  * Повна підтримка TypeScript для статичної типізації.
  * Вбудована легка інтеграція з Swagger для автоматичного документування API та з WebSocket/Pusher для сповіщень.
* **Компроміси та обмеження:**
  * Більш високий поріг входження та наявність шаблонного коду (boilerplate) порівняно з чистим Express.js.
