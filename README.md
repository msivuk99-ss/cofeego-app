# CoffeeGo — Мобільний застосунок та веб-система для мережі кав'ярень

**CoffeeGo** — це комерційна система попереднього замовлення напоїв без черг для мережі з трьох кав'ярень. Дозволяє клієнтам обирати напої, оплачувати замовлення онлайн та отримувати бонуси, а баристам — приймати й готувати замовлення в реальному часі.

---

## 🚀 Основні можливості

* **Для клієнтів (Мобільний додаток iOS/Android):**
  * Вибір однієї з 3-х кав'ярень мережі та перегляд актуального меню.
  * Оформлення замовлення з деталізацією (об'єм, сиропи, тип молока) та вибором часу видачі.
  * Безготівкова онлайн-оплата (Apple Pay, Google Pay, LiqPay, MonoPay).
  * Накопичувальна бонусна система (нарахування 10% від суми замовлення).
  * Отримання Push-сповіщень про зміну статусу замовлення («Готується», «Готово»).
* **Для баристи та менеджера (Веб-кабінет SPA):**
  * Оперативна зміна статусів замовлень баристою (Прийнято $\rightarrow$ Готується $\rightarrow$ Готово).
  * Кабінет менеджера для контролю замовлень по всіх трьох кав'ярнях.
  * Інтеграція з наявною POS-системою кав'ярні (Poster / iiko).
