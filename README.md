# CoffeeGo — Мобільний додаток та веб-кабінет кав'ярень

## Опис проєкту
Проєкт призначений для швидкого попереднього замовлення кави без черг, використання накопичувальної системи бонусів та автоматизації роботи баристи і менеджера мережі.

Тип системи: Cross-platform Mobile App (iOS/Android) + Web SPA (Панель баристи/менеджера) + REST API Backend.
Автори проєкту: Баль М., Сівук М. (Full-stack / Mobile & Backend Lead).
